HOW TO INSTALL (don't double-click, macOS will refuse):

1. Open Terminal (Cmd+Space, type Terminal, press Enter).
2. Paste this line and press Enter:

   bash ~/Downloads/chrome-optimizer-main/minecraft-blocker/install.command

3. Type your Mac password (it stays invisible while typing) and press Enter.

Folder not in Downloads? Type "bash " (with a space), drag install.command
into the Terminal window, press Enter.

This also creates the on/off app "Minecraft Blocker" in ~/Applications
(open it with Spotlight: Cmd+Space, type Minecraft Blocker).

To remove later:  bash /Library/MinecraftBlocker/uninstall.command
